# Tiny Tailwind v0.3.5

The standards catch-up. No new places, enemies or items. The game now has the same save slots, Settings, Menu and tester tools as the other games on The Game Shelf, plus a new app icon with the Manta.

## Five minute test

1. Install the APK over v0.3.4. The app icon is new: the Manta climbing on a golden tailwind over a night meadow. On Android 13 and newer, themed icons show the Manta alone.
2. Open the game. The title card shows one line of controls for what you used last, then Continue (slot 1), Play and Settings, and Version 0.3.5 near the top. Your v0.3.4 game is in slot 1.
3. Press Continue. You are back where you left off, with your keepsakes, coins and upgrades.
4. Open the Menu. A row reads Resume, Settings, How to play, Ship, Journal, Map, Title. Resume has the focus. Open How to play: every key, Xbox button and touch control, with the one you use marked "in use".
5. Open Settings. Music, Sound, Full screen, Frame rate, Rumble and Screen shake come first. Then Tiny Tailwind's own: Difficulty, Aim assist, Game speed, Invincible, Camera and the rest, the same choices as before. Then Text size, Reduce motion and Reset settings. Change Music to Low, close the app, open it again. Music is still Low. There is no Save button.
6. Press the Home button on your phone, then come back. The Menu is open and the game is paused.
7. Title, then Play. Five slots show. Pick Slot 2. A new game starts. Back on the title card, Play, then Delete on Slot 2. It reads Press again. Press it again. Slot 2 is empty.
8. Settings, Tester tools, then the code. Try Go to Keep hall and All keepsakes but one. A DEBUG tag shows at the top while the tools are unlocked.

## New in this version

- Five save slots. Continue opens the slot you played last. Play opens the slot list. Choosing an empty slot starts a new game there. Delete asks for a second press. Your v0.3.4 game moves into slot 1 on the first run.
- The shared Settings panel, on the title card and in the Menu. Music and Sound now step through Off, Low, Medium, High and Full. New: Text size (Normal, Large, Larger) and Reduce motion, which stops the screen shake, softens the red hurt flash and steadies the low heart warning. Every change saves at once. Settings belong to the device, so every slot shares them. Your old choices carry over.
- The Menu row follows the order every game uses: Resume, Settings, How to play, then Ship, Journal and Map, then Title.
- How to play: every control for the keyboard and mouse, the Xbox controller and touch, with the one in use marked. Settings, Controls opens it too, from the title card as well.
- The title card shows the controls for the device you used last, not all three.
- Hints follow the device in use: the dash hint and the Wagon's closing hint name keys, Xbox buttons or touch.
- The game pauses with the Menu open when you switch apps or tabs and when your controller disconnects. The Menu says why.
- Rumble now buzzes the phone as well as the controller. Settings, Rumble turns both off.
- Tester tools behind a code, in test builds only: go to every checkpoint, the warden's door and the Wagon, the Dash Core on and off, level up, upgrade points, full hearts, coins, every Wagon item, keepsakes, calm every fight but the warden, the warden to one hit, Difficulty, Invincible, Camera, Reset the save and Load the test save. Also build info, a frame rate and memory readout, game speed and Copy bug report.
- A new app icon from one large master, with the adaptive and themed layers Android uses.
- A privacy page: the game collects nothing and the APK asks for no internet. It asks only to vibrate.
- The old Erase save button is gone. Delete a slot in the slot list.
- The source moved to a private repo. This repo keeps the game page, the builds, the release notes and the backlog.

## Shared kit

Built with kit 1.9.1: the save store, Settings, save slots, the device watcher, the second press and Tester tools.

## Install

Version 0.3.5 installs over 0.3.4 and keeps your game.

## Full test checklist

1. The title card: the name, Version 0.3.5, the line on the game, one controls line, Continue (slot N) only when that slot holds a game, Play and Settings.
2. Five slots. An empty slot starts a new game. Delete needs two presses. Deleting the slot in use moves to another used slot or slot 1.
3. The Menu row: the order above, Close while open. Esc, View, Menu and the Android back button open and close it. B and Esc close Settings and the slot list first.
4. Settings: the standard six first, Tiny Tailwind's twelve, Controls, Text size Larger fits on a phone, Reset settings needs two presses, Rumble only on Android or with a controller.
5. Switch away and back: the game is paused with the Menu open. Turn a controller off while flying: the Menu opens with a line about the controller.
6. Hints: touch, keys and an Xbox controller each change the title card line and the mark in How to play.
7. Tester tools: the code unlocks them with touch, a keyboard and an Xbox controller alone. Copy bug report pastes into a chat.
8. Old save: your v0.3.4 game is in slot 1 with its keepsakes, coins, upgrades and fast travel points. Your old Camera, Difficulty and assist choices are in Settings.

## Not tested

- Real devices: no phone, tablet, Retroid or real Xbox controller was tried. Every play test ran in headless Chrome with the kit's pretend Xbox controller, and headless in Godot.
- The APK was built, signed and checked, but never installed. Install over v0.3.4, the Android back button, phone vibration, controller loss in the app and the themed icon wait for a real phone.
- Nobody listened to the game. The Music and Sound levels were checked in code and in the browser test, not by ear.
- Text size Large and Larger were not tried in the browser test. The kit scales the whole screen, so the game view gets larger too. That was not judged by eye.
