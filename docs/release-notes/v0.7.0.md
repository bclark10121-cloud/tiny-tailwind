# Tiny Tailwind v0.7.0

Tiny Tailwind moves to Godot 4.7.2, draws at your screen's own rate (up to 120 frames a second on your phone), opens full screen in the browser on the first tap and fills wide screens edge to edge. Release 3 (weapons) is next, as you said in the playtest sweep.

## Five minute test

1. Install the APK over v0.6.3. Your saves stay.
2. Fly and shoot for a minute. It feels the same, smoother on a 120 Hz screen.
3. Settings > Tester tools > Show frame rate (or Settings > Frame rate). It reads up to 120 while you fly.
4. In a browser, the first tap turns full screen on. Turning Full screen off in Settings is remembered.

## New in this version

- Smooth at up to 120 frames a second (G6.20): no 60 cap. A new frame check proves the Manta moves on every frame at 60, 90 and 120, at the same speed.
- Show frame rate in Tester tools.
- Full screen by default in the browser (G5.11, kit 1.17).
- 1080p and wider screens fill edge to edge (G6.21).

## Changed

- Godot 4.7.2 (G6.19). Kit 1.18.0.

## Install

Version 0.7.0 installs over 0.6.3 and keeps your saves.
