# Tiny Tailwind v0.1.1

A controller fix from the first playtest. Shared kit 1.5.0.

## New in this version

- The D-pad now flies the ship, the same as the left stick. In v0.1.0 only the left stick moved it.
- The title card and the Settings page say which controller the game sees, or that it sees none.
- The game page has steps for a ROG Ally or other Windows handheld: set Control Mode to Gamepad in Command Center.

## Test checklist

1. On the handheld, open Command Center and set Control Mode to Gamepad.
2. Open the game page and press Play in your browser. Press any button.
3. The title card shows a blue line: Controller, then the name of your controller. If it says none seen yet, the browser is not getting a gamepad.
4. Press A on Start. Fly with the left stick, then with the D-pad.
5. Aim and fire with the right stick.
6. Press View or Menu. Move with the D-pad, choose with A, go back with B.
7. Android: install the APK over v0.1.0. Your save stays.

## Known limits

- Tested headless only, with a pretend Xbox controller in headless Chrome. Not tested on a ROG Ally, a real controller or a real phone.
