# Tiny Tailwind v0.5.0

Release 7: the standards review pieces every game now shares. A Records page, button remapping, backup codes, Battery saver and steadier sound levels.

## Five minute test

1. Install the APK over v0.4.0. Your saves stay.
2. Press Play, pick your slot and play for a minute. Pick up a keepsake. A gold note says "Achievement: First Keepsake".
3. Open the Menu. Press Records. It lists 11 achievements with progress, then your stats: play time, keepsakes, level, sea creatures calmed and more.
4. Open Settings, then Change controls. Pick Dash and press another key or button. Dash moves there. If another action had it, the two swap. Reset controls puts everything back.
5. Open the slot list. Press Copy code on your slot. Paste the code into the box under the slots on another device and press Load code. It loads into the first empty slot.
6. Listen to the music. It should sound about as loud as before against the shots. Tell me if it doesn't.

## New in this version

- Records in the Menu: 11 personal achievements (one hidden) and 7 stats (G4.10, G4.11).
- Change controls in Settings: every move, aim and dash key and button. A clash swaps the two (G5.22).
- Battery saver in Settings caps the game at 30 frames a second (G6.12).
- Backup codes in the slot list: Copy code and Load code (G5.19).
- Every save now has a test copy, and each release checks that old saves still load (G5.24).
- An error log on the device. Copy bug report in Tester tools adds the last ten errors (G5.27).
- Music and sounds brought to one loudness level (G5.28). The music player was turned up to match, so the mix stays as you set it on 2026-11-16.
