# Tiny Tailwind: plan before the build

Written 2026-11-15. G4.8 (Proposed) asks for a review, a plan and a backlog before any build.

| Item | What it is | How it was used |

## 2. Borrow and leave

Borrow (structure): twin-stick control, an open overworld with a cave and a dungeon, a gate ability, crystals spent on ship stats, close checkpoints, assist options.

Leave (content): every picture, sound, map, name, character and number in the reference. None of it is in this repo (G8.4). The attachment stays out of the repo.

## 3. Name check

- Web searches on 2026-11-15 found no game called Tiny Tailwind.
- Near names: Tailwind: Prologue, a space shooter by another studio, and several small games with Tiny in the title. BC's own Tiny Titans Football also starts with Tiny.
- BC chose Tiny Tailwind on 2026-11-15 after seeing these notes. The working title before that was a different name.
- Limits: a web search only. Trademark records and the Play Store were not searched.
